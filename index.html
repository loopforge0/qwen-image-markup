Size budget
Size budget 0 keeps the image at its own size. 2048 is the model’s native 2K — about 19 minutes for one edit on a 12 GB card, against about 50 seconds at 1 MP.
Session
A session keeps the image, the marks and the prompt. The marked PNG and the prompt are all a stock ComfyUI edit graph needs to reproduce a run without this app.
ComfyUI
Point this at any ComfyUI on the network. The marked image is uploaded over the API, so it does not have to be on this machine.
